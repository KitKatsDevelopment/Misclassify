# Vouches

Drop a screenshot of each person's vouch in this folder, named **after the
person** exactly as they appear on the site. The site already hardcodes the
lookup, so no code changes are needed — the file just has to be here.

Clicking a vouch's wording on the site reveals that person's screenshot.

## Expected file names

| Person      | File to add            |
| ----------- | ---------------------- |
| Scrainyr    | `Scrainyr.png`         |
| Melly       | `Melly.png`            |
| Daniel      | `Daniel.png`           |
| pxtf        | `pxtf.png`             |
| Cosmic Risk | `Cosmic Risk.png`      |
| Amber       | `Amber.png`            |
| DaisyLGBT   | `DaisyLGBT.png`        |
| Ch3rry      | `Ch3rry.png`           |

`.png` is used first, but `.jpg`, `.jpeg`, `.webp` and `.gif` also work — the
first one that exists is the one that loads.

Names must match the voucher's name exactly (including spaces and capital
letters). If a screenshot is missing, the card shows a note saying which file
to add.
